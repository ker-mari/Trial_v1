                        HOW TO CHANGE PINS LATER
================================================================================

Option 1: Update the Seeder (for fresh installations)
   Edit: backend/database/seeders/PinSeeder.php
   Change the PIN values in Hash::make('XXXXXX')
   Run: php artisan migrate:fresh --seed

Option 2: Direct Database Update (for existing data)
   Use Laravel Tinker:
   
   php artisan tinker
   
   Then run:
   $pin = App\Models\Pin::where('user_name', 'Mr. Guard 1')->first();
   $pin->pin_hash = Hash::make('NEW_PIN_HERE');
   $pin->save();

Option 3: Create a PIN Management Interface (recommended for production)

================================================================================
                            TROUBLESHOOTING
================================================================================

If a user forgets their PIN:
1. Admin must update their PIN in the database (see Option 2 above)
2. Communicate new PIN securely
3. Consider implementing a "forgot PIN" feature for production

If a PIN is compromised:
1. Immediately deactivate the user in the database:
   $pin = App\Models\Pin::where('user_name', 'USERNAME')->first();
   $pin->is_active = false;
   $pin->save();

2. Generate a new PIN for the user
3. Investigate any suspicious activity in the logs
